# Idea Finder

Autonomous SaaS platform for market intelligence and friction scraping. Powered by a 7-agent AI team managed via Notion and Claude Scheduled Tasks.

## Project Structure
- `prompts/` - System prompts for the 7 Claude agents
- `scripts/` - Notion integration & automation scripts
- `backend/` - Java 21 & Spring Boot 3 REST API service
- `frontend/` - React, Vite & Tailwind CSS dashboard
